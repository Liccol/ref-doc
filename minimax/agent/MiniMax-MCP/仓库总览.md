## 定位与核心能力

这是 Python MCP 工具服务，将 MiniMax 音频、图像和视频 API 暴露给支持 MCP 的客户端。客户端负责对话和任务规划，服务负责工具接口和 API 调用。README 还推荐 MiniMax CLI 作为另一种接入方式，但这不能证明 MCP 的接口已被替代或停止维护。来源：[README.md](https://github.com/MiniMax-AI/MiniMax-MCP/blob/0856b9aef8a9d676bb63bdd6b6426d7b640a3b7a/README.md)。

| 工具 | 职责 |
| --- | --- |
| `text_to_audio` | 文本转语音 |
| `list_voices` | 查询可用声音 |
| `voice_clone` | 基于音频克隆声音 |
| `play_audio` | 播放音频；源码已注册，README 工具表未列出 |
| `generate_video` | 创建视频生成任务 |
| `query_video_generation` | 查询视频任务结果 |
| `text_to_image` | 图像生成 |
| `voice_design` | 根据描述和预览文本设计声音 |

工具清单以 [minimax_mcp/server.py](https://github.com/MiniMax-AI/MiniMax-MCP/blob/0856b9aef8a9d676bb63bdd6b6426d7b640a3b7a/minimax_mcp/server.py) 的实际注册为准；不要只根据 README 表格统计接口数量。

## 代码结构与阅读入口

| 目录或文件 | 职责 |
| --- | --- |
| `minimax_mcp/server.py` | MCP 服务、工具注册、参数与结果处理 |
| `minimax_mcp/client.py` | MiniMax API 请求封装 |
| `minimax_mcp/const.py` | 常量和配置相关定义 |
| `minimax_mcp/utils.py` | 文件、资源与输出辅助函数 |
| `minimax_mcp/exceptions.py` | API 与请求错误 |
| `minimax_mcp/__main__.py` | Python 模块入口 |
| `pyproject.toml` | 依赖、版本与 minimax-mcp 命令入口 |
| `.env.example`、`mcp_server_config_demo.json` | 环境变量和 MCP 客户端配置示例 |
| `tests/`、`scripts/` | 服务/工具测试与开发脚本 |

建议沿“注册工具 → 构造 API 请求 → 处理异步结果 → 输出本地文件或 URL”阅读。

## 接入方式与已核查边界

该快照 `pyproject.toml` 声明 Python >=3.10、源码版本 0.0.19，并要求 `mcp[cli]>=2.0.0,<3`。这是源码声明，本次未核查 PyPI 最新发布。来源：[pyproject.toml](https://github.com/MiniMax-AI/MiniMax-MCP/blob/0856b9aef8a9d676bb63bdd6b6426d7b640a3b7a/pyproject.toml)。

MCP 客户端配置使用 `uvx minimax-mcp -y`，环境变量包括 `MINIMAX_API_KEY`、`MINIMAX_API_HOST`、`MINIMAX_MCP_BASE_PATH` 和 `MINIMAX_API_RESOURCE_MODE`。资源模式可选择 URL 或本地文件，区域 host 需与 key 匹配。

README 说明 stdio 与 SSE 两种传输，但当前入口 `main()` 仅调用 `mcp.run()`，没有展示 SSE 启动参数。本次未运行 SSE 部署，我不确定仅使用 README 的客户端配置是否足以启动 SSE 服务。来源：[README.md](https://github.com/MiniMax-AI/MiniMax-MCP/blob/0856b9aef8a9d676bb63bdd6b6426d7b640a3b7a/README.md)、[minimax_mcp/server.py](https://github.com/MiniMax-AI/MiniMax-MCP/blob/0856b9aef8a9d676bb63bdd6b6426d7b640a3b7a/minimax_mcp/server.py)。
