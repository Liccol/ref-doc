# MiniMax Code 特性变更总结（2026-10-29 ～ 2026-11-04）

## 新特性与能力扩展

### 0.7.2：Agent 工具执行与扩展能力

0.7.2 新增默认关闭的 Programmatic Tool Calling（PTC）：启用 `beta.ptc`、`mcode --ptc` 或 `mcode exec --ptc` 后，Agent 可用沙箱中的 `run_code` 组合 `read`、`grep`、`bash` 等调用，只把过滤后的结果带回上下文；仅对新 Session 或下一次 compaction 生效，read-only subagent 仍直接调用工具。插件可声明 subagent 和 Apps，MCP 工具超过 64 个或 schema 过大时改由 `tool_search` 按需加载，插件 MCP 原 128 工具上限取消。

同一版本还加入 prompt suggestions、TUI headless Browser Use 的 `run_script`、ACP 图片输入/会话重放、统一的 `requestMedia` 图片尺寸与请求预算、`permission.nativeDelete`（默认关闭）及 Windows hard-safety opt-out。`nativeDelete=true` 会使用原生命令、删除可能不可恢复，但权限模式、沙箱和根目录/主目录递归删除保护仍保留。[#566](https://github.com/MiniMax-AI/minimax-code/pull/566)

### TypeScript 与 Python SDK

新增 `@minimax-ai/code-sdk` TypeScript SDK 和 `minimax-code-sdk` Python SDK（import `minimax_code`，Python 3.10+）。两者通过每个 turn 启动 `mcode exec --output-format=stream-json` 来创建/继续 Session，提供 typed events、streaming、取消、同步/异步包装及恢复 thread；最低 CLI 版本为 0.6.3。该 exec-per-turn transport 暂不支持交互审批 `permission="ask"` 或在 SDK 进程中定义工具，计划中的 ACP transport 不属于本期已实现能力。[#553](https://github.com/MiniMax-AI/minimax-code/pull/553)、[#571](https://github.com/MiniMax-AI/minimax-code/pull/571)

Python SDK 随后增加 PyPI 发布流程，先发布 `0.1.0b1`，再发布 `0.1.0` 与 `0.1.1`；这些版本提交直接进入 main，没有对应 PR。`0.1.1` 包含流式 README 示例保留 `item.started` delta，以及在已运行 event loop 中使用 `SyncMCode` 时更安静的错误处理。[8c842ea](https://github.com/MiniMax-AI/minimax-code/commit/8c842eaaf7910ae8bc9dffb7a1a48d297d500013)、[a5a05c2](https://github.com/MiniMax-AI/minimax-code/commit/a5a05c23cd9ffe2ef4b5c339e165a9aa8220efcd)、[16f93d5](https://github.com/MiniMax-AI/minimax-code/commit/16f93d5b3fc68299a075df25bb90fddeeb4e547d)、[3c21163](https://github.com/MiniMax-AI/minimax-code/commit/3c21163c85a9684030cb147bfef48c6284fa3c46)

## 使用边界

- 0.7.2 的完整改动很多；本文只保留 Agent 执行、会话/上下文、文件与 Shell、权限、MCP/插件、TUI/exec/ACP 及影响使用的发布变更。
- PR 中的测试结果主要来自单元、fake CLI、macOS/Linux 与部分真实 CLI 验证；除明确说明外，本次没有重新运行 MiniMax 在线模型、Computer Use 或 Windows 端到端测试。
- Python SDK resume 的 Session 必须继续使用创建时的 workspace/cwd；SDK transport 仍依赖本机可用且版本满足要求的 `mcode` CLI。
