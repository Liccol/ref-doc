## 定位与核心能力

这是 MiniMax 平台的多模态命令行工具，npm 包为 `mmx-cli`，执行命令为 `mmx`。它供终端用户、脚本和其他 Agent 调用平台 API，并提供 SDK 与技能资源。它与执行编码任务的 `mcode` 职责不同。来源：[README.md](https://github.com/MiniMax-AI/cli/blob/06e47c70b76f419196678367dae62acca4c94076/README.md)、[SDK.md](https://github.com/MiniMax-AI/cli/blob/06e47c70b76f419196678367dae62acca4c94076/SDK.md)。

| 能力 | 内容 |
| --- | --- |
| 文本 | 多轮 chat、流式响应、system prompt 和 JSON 输出 |
| 图像 / 视频 | 图像生成；异步视频任务创建、查询和下载 |
| 语音 | 合成、voice 列表、流式输出及语音转写 |
| 视觉 / 搜索 | 图像理解与 MiniMax 搜索 |
| 认证 / 配置 | OAuth 或 API key，Global / CN 区域，配置与额度查询 |
| Agent 配置辅助 | `mmx agent setup` 为选定外部 Agent 配置 MiniMax |
| SDK / Skill | TypeScript SDK 入口与面向 Agent 的能力说明 |

README 列有 H3 视频和语音转写的具体参数、文件边界，后续升级时应按对应命令实现核对，不把模型名称变化直接理解为所有任务都已兼容。

建议先读命令注册和所关心的命令，再跟进 client、SDK、认证和错误处理。目录以该快照为准：[源码树](https://github.com/MiniMax-AI/cli/tree/06e47c70b76f419196678367dae62acca4c94076/src)。

## 使用方式与边界

README 要求 Node.js 18+，通过 `npm install -g mmx-cli` 安装；执行 `mmx auth login` 后使用 `mmx text chat --message "Hello"`、`mmx image "A cat"` 或 `mmx quota`。本次未实际安装或认证。

OAuth 与 API key 登录互斥；README 说明凭据保存在用户配置中，支持自动刷新和手动 `mmx auth refresh`。Global / CN 平台使用不同 API host。服务能力和额度受账号授权约束。

`mmx agent setup` 是外部 Agent 的配置辅助入口；非交互调用不会启动 Agent。README 列出 Claude Code、Codex、Grok Build、OpenCode、Hermes 和 Pi。该列表可能随版本变化，统计变更时应以实际配置器为准。来源：[README.md](https://github.com/MiniMax-AI/cli/blob/06e47c70b76f419196678367dae62acca4c94076/README.md)。
