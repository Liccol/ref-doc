# MiniMax CLI 变更记录（2026-10-08 ～ 2026-10-14）

## 新特性与行为变化

| 日期 | 特性 | 变化与使用边界 | 来源 |
| --- | --- | --- | --- |
| 10-12 | M3.1 默认模型与 Oh my Pi 配置 | `text chat`、`text repl` 和 SDK 在没有显式/已保存模型选择时，默认改为 `MiniMax-M3.1-Flash-Preview`；显式选择仍优先，按量付费 key 的 Agent setup fallback 仍是 `MiniMax-M3`。`mmx agent setup --agent oh-my-pi`（别名 `omp`）新增检测、安装及 China/Global `models.yml` / `config.yml` 写入，保留其他设置并使用原有备份与私密写入机制；旧 JSON-only 配置需先由 `omp` 迁移 | [#282](https://github.com/MiniMax-AI/cli/pull/282) |

该 PR 的作者使用 Oh my Pi 18.10.1 和本地 Anthropic mock 验证了生成配置及请求字段；本文未独立调用 MiniMax 服务验证账号可见模型和额度。
