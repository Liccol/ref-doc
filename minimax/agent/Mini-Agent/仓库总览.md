## 定位与核心能力

这是 Python 单 Agent 示例，适合学习和扩展“调用模型 → 执行工具 → 回传结果 → 继续推理”的完整循环。README 以 MiniMax M2.5 为例，源码同时具有 Anthropic 与 OpenAI 客户端适配，不宜将 README 示例模型视为唯一支持模型。来源：[README.md](https://github.com/MiniMax-AI/Mini-Agent/blob/d76a4f6389688cabda39c224a6cdfa274215d47c/README.md)、[mini_agent/llm/llm_wrapper.py](https://github.com/MiniMax-AI/Mini-Agent/blob/d76a4f6389688cabda39c224a6cdfa274215d47c/mini_agent/llm/llm_wrapper.py)。

| 能力 | 主要内容 |
| --- | --- |
| Agent 循环 | 模型交互、工具分发、执行步数与取消处理 |
| 文件与 Shell 工具 | 为 Agent 提供工作区操作能力 |
| 上下文管理 | 在本地估算或 API 上报 token 超过阈值时压缩执行历史；源码默认 token_limit 为 80000，不等于模型固定上下文上限 |
| 会话笔记 | 通过 Session Note 工具保存任务关键信息 |
| Skills / MCP | 载入技能和外部 MCP 工具，扩展 Agent 可执行动作 |
| 编辑器集成 | 提供 mini-agent-acp 入口，README 展示 Zed 接入 |

Agent 循环和压缩行为见 [mini_agent/agent.py](https://github.com/MiniMax-AI/Mini-Agent/blob/d76a4f6389688cabda39c224a6cdfa274215d47c/mini_agent/agent.py)。

## 使用方式

源码要求 Python >=3.10。项目通过 uv 管理依赖；开发模式运行 `uv sync`，配置 `mini_agent/config/config-example.yaml` 对应的 API key、API base 和模型后，使用 `uv run python -m mini_agent.cli`。工具安装方式为 `uv tool install git+https://github.com/MiniMax-AI/Mini-Agent.git`，随后按 README 初始化用户配置，启动 `mini-agent --workspace /path/to/project`。

配置的 API host 必须与所用平台匹配。入口和 Python 要求见 [pyproject.toml](https://github.com/MiniMax-AI/Mini-Agent/blob/d76a4f6389688cabda39c224a6cdfa274215d47c/pyproject.toml)；完整步骤见 [README.md](https://github.com/MiniMax-AI/Mini-Agent/blob/d76a4f6389688cabda39c224a6cdfa274215d47c/README.md)。
