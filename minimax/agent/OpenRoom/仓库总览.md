## 定位与核心能力

仓库名称是 OpenRoom，当前 README 标题为 **VibeApps**。项目提供浏览器桌面：窗口、内置应用、聊天面板和结构化 Action 系统。Agent 通过应用声明的动作读取和修改状态，而不是通用桌面截图点击执行器。来源：[README.md](https://github.com/MiniMax-AI/OpenRoom/blob/02468154c4d99f8925916425bf444d672454fb3d/README.md)、[apps/webuiapps/src/lib/action.ts](https://github.com/MiniMax-AI/OpenRoom/blob/02468154c4d99f8925916425bf444d672454fb3d/apps/webuiapps/src/lib/action.ts)。

| 能力 | 内容 |
| --- | --- |
| 浏览器桌面 | Shell、应用窗口、窗口管理与多个应用并排运行 |
| 内置应用 | 音乐、棋类、邮件、日记、社交 feed、相册和新闻等示例 |
| Agent 操作 | 应用 Action、执行结果回传与生命周期通知 |
| 本地存储 | 开源独立模式使用 IndexedDB 与本地事件通信 |
| 对话与状态 | 聊天历史、模型配置、记忆和应用注册相关模块 |
| 应用开发工作流 | Claude Code 中的 `/vibe` 用于创建或修改应用 |

应用存在相应 UI 和示例数据，不代表本次已验证邮件、社交或新闻应用连接真实外部服务。

## 代码结构与阅读入口

| 目录或文件 | 职责 |
| --- | --- |
| `apps/webuiapps/src/components/` | Shell、AppWindow、ChatPanel |
| `apps/webuiapps/src/lib/action.ts` | Action 协议、事件上报、监听和结果回传 |
| `apps/webuiapps/src/lib/appRegistry.ts` | 应用注册 |
| `apps/webuiapps/src/lib/llmClient.ts` | LLM 客户端 |
| `apps/webuiapps/src/lib/memoryManager.ts` | 记忆管理 |
| `apps/webuiapps/src/lib/vibeContainerMock.ts` | 独立模式的通信与存储 mock |
| `apps/webuiapps/src/pages/` | 内置应用 UI、数据与动作 |
| `packages/vibe-container/` | iframe 通信 SDK 接口与类型 |
| `.claude/commands/`、`.claude/workflow/` | Vibe 开发命令和阶段定义 |
| `apps/webuiapps/src/lib/__tests__/` | 客户端、存储和日志等测试 |

Action 数据包含 app_id、action_id、action_type、params、timestamp_ms 和 trigger_by。监听器按 app_id 路由动作，执行后回传 action_result，包含异步失败路径。它是理解跨应用 Agent 操作的主要入口。来源：[apps/webuiapps/src/lib/action.ts](https://github.com/MiniMax-AI/OpenRoom/blob/02468154c4d99f8925916425bf444d672454fb3d/apps/webuiapps/src/lib/action.ts)。

## 使用方式与职责边界

README 要求 Node.js 18+、pnpm 9+，通过 `pnpm install`、`pnpm dev` 启动，访问 `http://localhost:3000`。主要技术栈为 React 18、TypeScript、Vite 和 pnpm workspace；配置与依赖见 [package.json](https://github.com/MiniMax-AI/OpenRoom/blob/02468154c4d99f8925916425bf444d672454fb3d/package.json)。

浏览器桌面和本地存储可在独立模式工作，但聊天 Agent 仍需在 Chat Panel 配置 LLM API key。README 的“本地运行”不意味着模型推理在浏览器内离线完成。

应用内聊天用于操作现有应用；生成和修改应用的 `/vibe` 在 Claude Code 开发环境执行。独立模式使用本地 mock，不能据此推断开源仓库包含线上平台全部后端。来源：[README.md](https://github.com/MiniMax-AI/OpenRoom/blob/02468154c4d99f8925916425bf444d672454fb3d/README.md)。
