# 2026 年 10 月 29 日至 11 月 4 日 vLLM Router 与 SGLang Model Gateway 变更记录

## vLLM Router

### 新特性与行为变更

| 日期 | 特性 | 变化与使用边界 | 来源 |
| --- | --- | --- | --- |
| 11-02 | Rust gRPC P/D | `--vllm-pd-disaggregation` 支持 `grpc://` prefill/decode worker 的 `/v1/chat/completions`：router 只 tokenize 一次，P unary prefill 的 KV 参数转交 D streaming decode，并保留 DP-rank、指标和 NIXL push 并发路径。其他 endpoint 在 gRPC P/D pool 上仍返回 400，不能据此推断 gRPC P/D 已覆盖 Responses/Completions | [#410](https://github.com/vllm-project/router/pull/410) |
| 11-03 | `sticky_least_loaded` 策略 | 新策略为新 session 选择当前 active session 最少的 replica、并用一致性哈希破同分；既有 session 继续固定到原 replica。可用于 `--policy`、`--prefill-policy`、`--decode-policy`，从 `X-Session-ID` 或若干顶层 JSON 字段识别身份；`POST /finish_session` 主动释放，默认 2 小时过期，可用 `VLLM_ROUTER_SLL_SESSION_EXPIRATION_IN_S` 覆盖。无 session 请求不计入状态 | [#347](https://github.com/vllm-project/router/pull/347) |
