# 2026 年 10 月 29 日至 11 月 4 日 vLLM Router 与 SGLang Model Gateway 变更记录

## vLLM Router

### 新特性与行为变更

| 日期 | 特性 | 变化与使用边界 | 来源 |
| --- | --- | --- | --- |
| 10-30 | KV event source 统一校验 | live subscriber 与 replay 在写入 KV index 前统一执行事件解码、topic/control frame 和 endpoint/source 校验；worker metadata 请求也复用配置的 backend API key。无效或来源不一致的事件不再影响 placement | [#401](https://github.com/vllm-project/router/pull/401) |
| 11-01 | Completion KV-aware 输入准备 | Regular/co-located HTTP `/v1/completions` 在重试前准备一次输入证据，每次 attempt 重新选择与预留 worker；Direct token IDs 直接使用，文本依赖 worker render/tokenize。无法建模的 adapter、salt 或扩展仍可路由，但不给 KV credit；普通 HTTP 用户无需本地 tokenizer 或新配置 | [#396](https://github.com/vllm-project/router/pull/396) |
| 11-02 | PD warm remote KV 复用 | Program scheduling 新增默认关闭的 `pd.advanced.warm_remote`，下一 turn 可在来源、epoch、lease、精确 prompt prefix 和覆盖率均验证后读取上一 turn 的 D-source KV；任一条件失败回退 `ColdRemote`。同时可用 `pd.advanced.automatic_ttl`/`ttl_online` 根据在线 inter-turn 间隔拟合 seat TTL；不包含 LocalAppend、Store 或联合 P×D 路由 | [#461](https://github.com/vllm-project/router/pull/461) |
| 11-02 | workflow prediction shadow profiles | Program Scheduling 增加 workflow 条件化的 return-time 与 output-length predictor，可由离线 seed 加在线 histogram、分层回退和成熟阈值形成 profile。当前仅 shadow 记录/评估，不改变 TTL deadline、pause 排序或 admission，生产调度仍使用显式 TTL 与原 rank-level fallback | [#375](https://github.com/vllm-project/router/pull/375) |
| 11-02 | Rust gRPC P/D | `--vllm-pd-disaggregation` 支持 `grpc://` prefill/decode worker 的 `/v1/chat/completions`：router 只 tokenize 一次，P unary prefill 的 KV 参数转交 D streaming decode，并保留 DP-rank、指标和 NIXL push 并发路径。其他 endpoint 在 gRPC P/D pool 上仍返回 400，不能据此推断 gRPC P/D 已覆盖 Responses/Completions | [#410](https://github.com/vllm-project/router/pull/410) |
| 11-03 | `sticky_least_loaded` 策略 | 新策略为新 session 选择当前 active session 最少的 replica、并用一致性哈希破同分；既有 session 继续固定到原 replica。可用于 `--policy`、`--prefill-policy`、`--decode-policy`，从 `X-Session-ID` 或若干顶层 JSON 字段识别身份；`POST /finish_session` 主动释放，默认 2 小时过期，可用 `VLLM_ROUTER_SLL_SESSION_EXPIRATION_IN_S` 覆盖。无 session 请求不计入状态 | [#347](https://github.com/vllm-project/router/pull/347) |

### 问题修复与性能

本期没有需要另列的独立问题修复；上述 KV event 校验与 prepared Completion 输入同时修正了运行路径的一致性与失败回退边界。
